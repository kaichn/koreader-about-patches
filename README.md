# ✓ About: Active Patches

**A [KOReader](https://github.com/koreader/koreader) user patch that lists your active user patches in Help → About.**

```
✓ 2-cwng-offline-guard.lua
   CWNG sync: pauses after a failed connection…
⚠ FAILED: 2-broken.lua
```

Each patch gets ✓ if it loaded or ⚠ if it failed. Add a one-line description for any patch in the `DESCRIPTIONS` table.

## Install
Copy `2-about-active-patches.lua` to `koreader/patches/` and restart KOReader.

Tested with KOReader 2026.07.2. MIT license.
